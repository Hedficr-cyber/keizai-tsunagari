# 経済のつながり

経済・金融・ビジネスのニュースと、有識者の発信を集めて、「何が起きたか」だけでなく「それが何につながり、この先どうなるかもしれないか」を学ぶ個人用アプリ（PWA）。

- 公開版：https://hedficr-cyber.github.io/keizai-tsunagari/ （iPhone の Safari で開き、共有 →「ホーム画面に追加」）
- リポジトリ：https://github.com/Hedficr-cyber/keizai-tsunagari

公開版は **v0.7.1（2026-10-29）**。下のメニューをリキッドグラス風にし、メニュー上のスライドと画面の左右スワイプで4画面を切り替えられる。

## 画面

| 画面 | できること |
|---|---|
| 今日 | 今日の一言、相場（ドル円・日米の10年金利）、週のまとめ（週末）、今日のテーマ（一覧は「ひとことで」とつながりだけ。タップで、何が起きた？・どうつながる？・この先どうなるかも・次に見るもの・有識者・元のニュース）、これからの予定（タップで結果しだいの2通り）、いま動いているもの |
| ニュース | 「一覧」：全件を最初から見出し・出典・時刻で表示。「すべて」の先頭は、重要度と分野の広がりで最大5本を置き、残りは分野ごとに並べる。「すべて・重要・分野」の分類はそのまま。タップで「何が起きた？・背景と仕組み・この先の影響・次に見ること」をアプリ内で読む。出典のリンクは詳細の最後にまとめる。「流れ」：テーマを日をまたいでつないだ時系列と、週のまとめの一覧 |
| つながり | 31項目・66の関係を、原因ごとのカードと結果・理由の行で一覧に。分類で絞り、各項目の上下を切り替えて関係を読む。関係をタップすると理由・反映の目安・暮らしへの関わり・関連ニュース、項目名や用語をタップすると意味が出る |
| 有識者 | 見方が分かれている点（強気と慎重）と、後藤達也さんの note・エコノミストの記事・研究所のレポートから、その人の見方を AI が短くまとめる |

文章の中の経済用語には点線が付き、タップすると意味が出る（`data/glossary.json` の134語と、その日の AI の「今日の用語」）。

ニュースは個人の好みで絞らず、世の中の流れをつかむために選ばれた全件を表示する。つながりは方向と理由を同じ一覧で読み、条件に左右されやすい関係は「条件しだい」と示す。

## v0.7.0の変更

- 「学ぶ」タブとクイズを外した。用語・項目のタップ説明、詳細の履歴とフォーカス、ニュースの全件と分類は維持した。

## v0.6.3で修正済みの点

- AI投資額と株価、米企業の原材料費と日本の輸入物価、中国の政治と景気を区別し、見出し・配信要約に根拠のない札を付けない。確かめられた対象の増減だけを使い、推測する影響は見通しの文章に分ける。保存済みのニュースにも同じ確認を適用した。
- 更新時の一時的なGit通信障害は、回数を限って再試行する。通信待ちで読み解きを繰り返さず、認証・権限の問題はその回を終了する。
- 詳細画面ではTab・Shift+Tabの操作を詳細内に保ち、閉じたら元の操作位置へ戻す。

## v0.6.2で修正済みの点

- AIは記事1本ごとに要点を作り、統合はアプリ側で国・主体・対象期間・出来事を照合して行う。不確かな場合は独立した記事として残す。「集めている媒体」では収集・代表記事・関連記事を分けて数える。
- 元記事に根拠のない項目札や、国が異なる項目札を外す。下降したときの影響に、上昇時の理由をそのまま添えない。
- シナリオは複数の因果経路を `paths` で持つ。日銀・FRBの据え置きは `hold` とし、発言の姿勢と実際の利上げ・利下げを区別する。不明な辺や逆向きの関係は矢印で結ばない。
- 当時はクイズの回答を問題内容で引き継いだ。クイズ画面はv0.7.0で外した。
- タブごとの位置、詳細から次の詳細へ進んだ履歴、表示中の詳細が参照しているデータを保持する。自動更新が入っても、古い見出しを押して別の記事が開くことを防ぐ。

## データの流れ

1. `tools/collect.py` … RSS と Google ニュースの検索で 23 媒体（日経・ロイター・ブルームバーグ・NHK・朝日・時事・共同・東洋経済・ダイヤモンド・ITmedia・日経ビジネス・JBpress・日銀・金融庁・財務省・内閣府・BBC 日本語・CNN 日本語・CNBC・BBC Business・MarketWatch・FT など。媒体ごとに上限あり）、有識者（note・Google ニュースの名前検索・YouTube）、相場（欧州中央銀行のドル円、財務省の国債金利、米財務省の国債金利）を集めて `_work/raw/collected.json` へ。
2. `tools/analyze.py` … Mac に入っている Claude Code（デスクトップアプリの claude コマンド）を1回呼び、テーマ・つながり・ニュースの詳しい説明・見通し・有識者の見方を作って `data/latest.json` へ。日ごとの控えは `data/archive/`。
3. アプリは `data/graph.json`（つながり図。手で整えた基本の因果）と `data/latest.json` を読むだけ。

ニュースの選定は経済全体への重要度、幅広い分野、同じ出来事の重複抑制を重視する。個人の好みやクリックされやすさでは選ばず、原資料にない話題を分野の穴埋めで作らない。シナリオの経路は `tools/scenario_integrity.py` の `normalize_case` で、記事の統合と項目札は元資料との照合で整える。

手で更新するときは `zsh tools/update.sh`。1回およそ2分、Claude の利用枠を少し使う。

## 自動更新

- Mac の launchd（`~/Library/LaunchAgents/jp.hedficr.keizai-tsunagari.update.plist`）が、毎時5分に `tools/auto_update.py` を動かす。Mac が眠っていた時刻の分は、起きたときに1回まとめて動く。
- 毎回ニュースは集める（10秒ほど・利用枠は使わない）。Claude に読み解かせるのは、前回の読み解きから3時間たったとき、または2時間以上たって新しい見出しが80本以上たまったときだけ（夜中の0〜6時は6時間あける）。目安は `tools/auto_update.py` の先頭。今すぐ読み解かせたいときは `KEIZAI_FORCE=1` を付けて動かす。更新している間は `caffeinate -i -s` で Mac を眠らせない（電源につないでいれば最後まで動く。バッテリーでフタを閉じていると、次に起きたときに続きが動く）。
- 動かす場所は `~/Library/Application Support/keizai-app/repo`（GitHub の写し。毎回 GitHub の最新にそろえるので、手で直さない）。記録は `~/Library/Logs/keizai-app/update.log`。
- 流れ：最新のコードにそろえる → 集める → 読み解くかを決める → 読み解く → `data/` だけをコミットして push → GitHub Pages が1分ほどで反映。
- 読み解きに失敗した回は、公開中の版をそのまま残す。
- 止めるとき：`launchctl bootout gui/$(id -u)/jp.hedficr.keizai-tsunagari.update`。今すぐ1回動かすとき：`launchctl kickstart gui/$(id -u)/jp.hedficr.keizai-tsunagari.update`。

## 用語集を足す・直す

`data/glossary.json` の `terms` に1行足す。`t`＝用語、`a`＝同じ意味の言い方（文中ではこれも探す）、`c`＝分類（`cats` のどれか）、`e`＝高校生にわかる1〜2文、`n`＝関係するつながり図の項目（任意）。文中では長い言い方から先に探すので、「金利」と「長期金利」が両方あっても大丈夫。

## 日をまたぐデータ

- `data/threads.json`（流れ）：テーマを `thread` の名前でつなぐ。同じ日に何度更新しても、その日の最後の内容が残る。60日動きがない流れは消す。
- `data/reviews.json`（答え合わせ）：`tools/analyze.py --review`。3〜7日前の記録のうち、まだ確かめていない最新の日を1日1回。
- `data/weekly/年-W週.json`（週のまとめ）：`tools/analyze.py --weekly`。土日の最初の更新で1回。
- 試すときは `--dry-run`（`_work/dry/` に書く）と `--reuse`（前回の AI の結果を使い回す）。

## YouTube を取り込む（任意）

YouTube の公式の配信（RSS）は 2026-10 時点で止まっている。動画一覧のページを機械で読むのは YouTube の利用規約で禁じられているので、公式の YouTube Data API（無料の枠で足りる）を使う。

1. Google Cloud で「YouTube Data API v3」を有効にして、API キーを作る。
2. キーを Mac のこのファイルに保存する（GitHub には上げない）：`~/Library/Application Support/keizai-app/youtube_api_key`
3. 次の自動更新から、PIVOT・日経の動画・テレ東BIZ を取り込む。記録（update.log）にチャンネル名が出るので、取り違えがないか確かめる。

## 集める元を変える

`tools/sources.json` に1行足す。`rss`（URL）、`gnews`（Google ニュースの検索語）、`youtube`（チャンネルID）。

## 気をつけていること

- 記事の本文は取り込まない。見出し・媒体名・リンクと、AI が自分の言葉で書いた要点だけを持つ。
- 見通しは「〜かもしれない」で書かせ、売買のすすめはしない。
- 日経平均の数値データ（日経の公式 CSV）は転載禁止なので使っていない。
- X（旧Twitter）は有料 API が必要なため、いまは取り込んでいない。
- 米国の雇用統計・消費者物価の日程は、米労働省のページが機械の読み取りを断っているので、ニュースに出てきたものを AI が拾う。
