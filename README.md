# 経済のつながり

経済・金融・ビジネスのニュースと、識者の発信を集めて、「何が起きたか」だけでなく「それが何につながり、この先どうなるかもしれないか」を学ぶ個人用アプリ（PWA）。

- 公開版：https://hedficr-cyber.github.io/keizai-tsunagari/ （iPhone の Safari で開き、共有 →「ホーム画面に追加」）
- リポジトリ：https://github.com/Hedficr-cyber/keizai-tsunagari

公開版は **v0.5.0（2026-10-28）**。ニュースの全件表示を保ちながら、一覧の見せ方と、つながりの使い方を整理した。

## 画面

| 画面 | できること |
|---|---|
| 今日 | 今日の一言、相場（ドル円・日米の10年金利）、週のまとめ（週末）、今日のテーマ（一覧は「ひとことで」とつながりだけ。タップで、何が起きた？・どうつながる？・この先どうなるかも・次に見るもの・識者・元のニュース）、これからの予定（タップで結果しだいの2通り）、いま動いているもの |
| ニュース | 「一覧」：全件を最初から見出し・出典・時刻で表示。「すべて」の先頭は、重要度と分野の広がりで最大5本を置き、残りは分野ごとに並べる。「すべて・重要・分野」の分類はそのまま。タップで要点とこの先、関連情報は「このニュースは何につながる？」を開いて読む。「流れ」：テーマを日をまたいでつないだ時系列と、週のまとめの一覧 |
| つながり | 「影響を考える」：日銀の利上げ・円高・原油高の3例、または自分で選んだ条件から、暮らしや仕事への影響→理由→実際のニュースへ進む。「原因をたどる」：項目の原因と影響を大きく描き、タップでさかのぼったり先へ進んだりする。「全体図」：31項目・66本の因果で、経済の中での位置をつかむ |
| 識者 | 見方が分かれている点（強気と慎重）と、後藤達也さんの note・エコノミストの記事・研究所のレポートから、その人の見方を AI が短くまとめる |
| 学ぶ | 答え合わせ（3日ほど前の見通しがどうなったか）、つながりクイズ、今日のニュースのクイズ、用語集、つながり図の項目 |

文章の中の経済用語には点線が付き、タップすると意味が出る（`data/glossary.json` の134語と、その日の AI の「今日の用語」）。

ニュースは個人の好みで絞らず、世の中の流れをつかむために全件を表示する。つながりの段数は関係をたどる数で、何日後・何週間後という時間ではない。逆向きの力がぶつかる所は「綱引き」として示す。

## データの流れ

1. `tools/collect.py` … RSS（日経の見出しは Google ニュース経由、NHK、東洋経済、ダイヤモンド、ITmedia、日銀）、識者（note・Google ニュースの名前検索・YouTube）、相場（欧州中央銀行のドル円、財務省の国債金利、米財務省の国債金利）を集めて `_work/raw/collected.json` へ。
2. `tools/analyze.py` … Mac に入っている Claude Code（デスクトップアプリの claude コマンド）を1回呼び、テーマ・つながり・見通し・識者の見方・クイズを作って `data/latest.json` へ。日ごとの控えは `data/archive/`。
3. アプリは `data/graph.json`（つながり図。手で整えた基本の因果）と `data/latest.json` を読むだけ。

v0.5.0ではニュースの選定方針を、経済全体への重要度、幅広い分野、同じ出来事の重複抑制を重視する内容に変更した。個人の好みやクリックされやすさでは選ばず、原資料にない話題を分野の穴埋めで作らない。この指示は次の自動更新から使われる。今回、現在の `data/latest.json` は再生成していない。

手で更新するときは `zsh tools/update.sh`。1回およそ2分、Claude の利用枠を少し使う。

## 自動更新

- Mac の launchd（`~/Library/LaunchAgents/jp.hedficr.keizai-tsunagari.update.plist`）が、毎日 7:00・12:00・18:00 に `tools/auto_update.py` を動かす。Mac が眠っていた時刻の分は、起きたときに1回まとめて動く。更新している間は `caffeinate -i -s` で Mac を眠らせない（電源につないでいれば最後まで動く。バッテリーでフタを閉じていると、次に起きたときに続きが動く）。
- 動かす場所は `~/Library/Application Support/keizai-app/repo`（GitHub の写し。毎回 GitHub の最新にそろえるので、手で直さない）。記録は `~/Library/Logs/keizai-app/update.log`。
- 流れ：最新のコードにそろえる → 集める → 読み解く → `data/` だけをコミットして push → GitHub Pages が1分ほどで反映。
- 読み解きに失敗した回は、公開中の版をそのまま残す。
- 止めるとき：`launchctl bootout gui/$(id -u)/jp.hedficr.keizai-tsunagari.update`。今すぐ1回動かすとき：`launchctl kickstart gui/$(id -u)/jp.hedficr.keizai-tsunagari.update`。

## 用語集を足す・直す

`data/glossary.json` の `terms` に1行足す。`t`＝用語、`a`＝同じ意味の言い方（文中ではこれも探す）、`c`＝分類（`cats` のどれか）、`e`＝高校生にわかる1〜2文、`n`＝関係するつながり図の項目（任意）。文中では長い言い方から先に探すので、「金利」と「長期金利」が両方あっても大丈夫。

## 日をまたぐデータ

- `data/threads.json`（流れ）：テーマを `thread` の名前でつなぐ。同じ日に何度更新しても、その日の最後の内容が残る。60日動きがない流れは消す。
- `data/reviews.json`（答え合わせ）：`tools/analyze.py --review`。3〜7日前の記録のうち、まだ確かめていない最新の日を1日1回。
- `data/weekly/年-W週.json`（週のまとめ）：`tools/analyze.py --weekly`。土日の最初の更新で1回。
- 試すときは `--dry-run`（`_work/dry/` に書く）と `--reuse`（前回の AI の結果を使い回す）。

## YouTube を取り込む（任意）

YouTube の公式の配信（RSS）は 2026-10 時点で止まっている。動画一覧のページを機械で読むのは YouTube の利用規約で禁じられているので、公式の YouTube Data API（無料の枠で足りる）を使う。

1. Google Cloud で「YouTube Data API v3」を有効にして、API キーを作る。
2. キーを Mac のこのファイルに保存する（GitHub には上げない）：`~/Library/Application Support/keizai-app/youtube_api_key`
3. 次の自動更新から、PIVOT・日経の動画・テレ東BIZ を取り込む。記録（update.log）にチャンネル名が出るので、取り違えがないか確かめる。

## 集める元を変える

`tools/sources.json` に1行足す。`rss`（URL）、`gnews`（Google ニュースの検索語）、`youtube`（チャンネルID）。

## 手元で開く

`/opt/homebrew/bin/python3 -X utf8 _work/devserver.py 8790` → http://localhost:8790/

## 気をつけていること

- 記事の本文は取り込まない。見出し・媒体名・リンクと、AI が自分の言葉で書いた要点だけを持つ。
- 見通しは「〜かもしれない」で書かせ、売買のすすめはしない。
- 日経平均の数値データ（日経の公式 CSV）は転載禁止なので使っていない。
- X（旧Twitter）は有料 API が必要なため、いまは取り込んでいない。
- 米国の雇用統計・消費者物価の日程は、米労働省のページが機械の読み取りを断っているので、ニュースに出てきたものを AI が拾う。
